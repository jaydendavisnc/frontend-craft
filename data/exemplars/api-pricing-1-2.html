What counts as a row

A row is one timestamp at one location. Baseload meters the rows a request returns, so a year of hourly prices at one hub costs the same as a single request or as 8,760 requests for one hour each.

# One hub, one year, hourly
curl "https://api.baseload.dev/v1/lmp\
  ?location=HB_NORTH&market=day_ahead\
  &start=2025-01-01&end=2026-01-01\
  &interval=1h" \
  -H "Authorization: Bearer $BASELOAD_KEY"

Failed requests
4xx and 5xx responses return no rows and are not billed.
Repeat reads
One key is billed for a row once in any rolling 24 hours.
Operator revisions
Rows restated after publication are delivered at no charge.
Late intervals
Rows missing during an operator outage are billed only on arrival.
